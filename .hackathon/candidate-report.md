## 5. 比赛要求做什么

**一句话任务：** 用 Alpaca Trading API 加上 MCP 或 CLI 做一个会下期权单的自主交易 agent，并用全新 paper 账户提交。

- 主题 / 问题定义：自主 AI 交易 agent，在 paper 环境交易美股/期权等
- 强制 sponsor 技术 / API / chain：Alpaca Trading API，以及 Alpaca MCP server 或 Alpaca CLI
- 必须真实发生的 SDK / API / on-chain 行为：paper 账户真实下单；策略必须包含 options；起始资金 $100,000；提交 Alpaca account ID
- 提交物：项目、一页 write-up（AI logic / risk gates / Alpaca infra）、全新 paper 账户 ID
- 资格门槛（pass/fail）——与评分标准分开：复用旧 Alpaca 账户不可评审；必须 options；必须 MCP 或 CLI
- 官方评分权重 / 标准：页面未给出分项权重；Rule Book 禁止作弊和破坏公平的自动化

## 6. 风险与投入

| 维度 | 评级 | 说明 |
| --- | --- | --- |
| 构建复杂度 | High | 自主 agent + options + 指定 Alpaca 工具链 |
| 预计 Agent sessions | 6–10 | 基线、策略、风控、演示材料 |
| 用户投入时间（规划、凭据、审查、提交） | 中 | 报名、Alpaca paper KYC/开户、最终提交 |

三项主要风险（技术 / 规则 / 时间）：

1. 提交必须用全新 paper 账户，开发账户不能拿去评审。
2. 策略不含 options 或没用 MCP/CLI 会直接不合格。
3. 构建窗只到 9/4 08:00 PDT，领奖另需税务证件。

## 7. 开源地基检索与升级方向

先核验：提交须为原创 MIT 作品（Terms §16：original work, MIT unless specified）。可用带披露的既有开源仓库做地基。短名单按协调人指定，且已核验许可证与 pinned commit，排除本赛事 2026 提交。`alpacahq/alpaca-mcp-server` 只当 MCP 层，不当 foundation。

### 人工选择卡

#### 1. Pinned MIT trading snapshot（`pin-31374551`）

- 来源与奖项：公开 MIT 算法交易平台快照，非本赛事
- 代码地基：`vendor/pin-31374551/` @ `31374551bae6fd34a0fe56fe11d208f4ff04fbb4` · MIT
- 保留：已接 Alpaca Market API 的算法交易平台骨架
- 升级方向：加上强制 options 路径，并通过 Alpaca MCP 或 CLI 在全新 paper 账户下单
- 大幅改动：增加 options 执行；把现有交易循环接到 MCP/CLI 与 $100k paper 风控
- 本赛事 feature：全新 Alpaca paper 账户；options 必选；提交 account ID
- 为什么适合 / 主要风险：已经在用 Alpaca，但默认路径未必含 options / MCP
- 人工选择：`SELECT alpaca-trading-agents-2026@pin-31374551`

#### 2. TradingAgents（`trading-agents`）

- 来源与奖项：GitHub 多 agent LLM 交易框架，非本赛事
- 代码地基：https://github.com/TauricResearch/TradingAgents @ `a33fd4c0f134485a43553a2c23a63cb14adbd88f` · Apache-2.0
- 保留：多 agent 研究/交易分工与 LLM 编排
- 升级方向：执行层改到 Alpaca Trading API + MCP 或 CLI，并加入 options
- 大幅改动：替换经纪商/行情；补 options；按赛事要求把提交许可证收到 MIT（保留 Apache 声明）
- 本赛事 feature：自主 agent；MCP 或 CLI；全新 paper 账户
- 为什么适合 / 主要风险：agent 架构最完整；Apache-2.0 与提交 MIT 要求需要处理
- 人工选择：`SELECT alpaca-trading-agents-2026@trading-agents`

#### 3. TradeAgent（`trade-agent`）

- 来源与奖项：GitHub AI 交易系统，非本赛事
- 代码地基：https://github.com/enving/TradeAgent @ `f5023d1a932bdecfe4d8ccdfaae871b14c4d0fe0` · MIT
- 保留：情绪分析、自适应参数、风控模块
- 升级方向：接到 Alpaca paper，并用 MCP 或 CLI 下期权单
- 大幅改动：增加 Alpaca 执行层与 options；对齐 $100k paper 规则
- 本赛事 feature：options；MCP/CLI；全新 paper 账户 ID
- 为什么适合 / 主要风险：风控现成，缺 Alpaca options / MCP 路径
- 人工选择：`SELECT alpaca-trading-agents-2026@trade-agent`
